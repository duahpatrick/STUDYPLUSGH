Computer Basics

Review how computers process information and the relationship between hardware and software.

Key idea

Computers work because hardware, software and users communicate together to accomplish tasks.

Hardware and Software Working Together

Hardware is the physical equipment: motherboard, processor, memory, storage, monitor, keyboard. Software is the instructions that make hardware useful: operating systems, applications and programs.

Without software, hardware cannot do anything useful. Without hardware, software has no place to run.

The Processing Cycle

Input: Keyboard or mouse sends data to the computer. Processing: The CPU works on the data. Output: Monitor or speaker shows the result. Storage: The result is saved to the hard drive or cloud.

You type text (input), the computer processes it (processing), you see it on screen (output), and you save the file (storage).

Memory and Storage

RAM (Random Access Memory) is temporary storage used while programs run. It is fast but clears when you turn off the computer. Storage (hard drive, SSD) is permanent. It holds files even after shutdown.

Operating Systems

An operating system (Windows, macOS, Linux, Android, iOS) manages hardware and applications. It provides a user interface, runs programs, manages files and controls devices.

Computer Care and Maintenance

Keep equipment clean and dry. Shut down properly by using the menu, not the power button. Update software regularly. Scan for viruses with antivirus software. Avoid spilling liquids near equipment.

Quick Check

What is the difference between RAM and storage?

RAM is temporary memory used while programs run. Storage is permanent and holds files even after shutdown.

Remember

Hardware and software are partners. RAM is for working; storage is for keeping. Proper care keeps computers running well.
