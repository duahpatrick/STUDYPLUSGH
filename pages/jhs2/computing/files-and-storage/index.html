Files and Storage

Organise digital work, protect files and use storage devices safely.

Key idea

Good file management keeps work easy to find, protects important data, and makes backing up simple.

Creating an Effective Folder Structure

Organize work into main folders by subject or year, then create subfolders for specific topics. Name folders clearly so anyone can find files. Avoid generic names like "Documents1" or "Folder".

Good structure: Documents > School > JHS2 > Mathematics > Algebra > Assignment1.docx

Naming Files Correctly

Use descriptive names that explain the content and include dates if needed. Keep names short but clear. Use underscores or hyphens instead of spaces. Avoid special characters that some systems don't recognize.

Good: Mathematics_Algebra_Assignment_2026-08.docx | Bad: homework.docx or Math Homework!!!.docx

Storage Devices and Cloud Services

Local storage: Hard drives (internal), external drives, USB flash drives. Cloud storage: Google Drive, Dropbox, OneDrive (accessible from any computer). Cloud storage provides automatic backup and easy sharing.

Advantages of cloud: accessible anywhere, automatic backups, easy sharing. Disadvantages: requires internet, privacy concerns.

Backing Up Important Files

Backup means making a copy of your files. Store backups in a different location from the original. Use the 3-2-1 rule: 3 copies of data, 2 different storage types, 1 copy off-site.

File Compression and Archiving

Compressed files use less storage space and transfer faster. ZIP is the most common format. Larger files or multiple files are often compressed before sharing.

Original file 50MB → Compressed file 15MB (saves space and transfers faster)

Quick Check

What is the advantage of using cloud storage for schoolwork?

Cloud storage is accessible from any computer, provides automatic backups, and makes sharing with teachers easy.
