JHS 2 Computing

Input and Output

Understand how data flows into, through and out of a computer system.

Key idea

Input devices send information to the computer; output devices present results back to users.

Input Devices

Input devices convert human actions into signals the computer understands. Common examples: keyboard, mouse, touchscreen, scanner, microphone, joystick, webcam.

Each input device serves a specific purpose: keyboard for text, mouse for pointing, scanner for images, microphone for voice.

Output Devices

Output devices convert computer signals into information humans can understand. Common examples: monitor, printer, speaker, projector, headphones.

Monitors display visual information. Printers produce paper copies. Speakers and headphones produce sound. Projectors display on a large screen.

The Input-Processing-Output Cycle

Input: User provides data or commands. Processing: Computer manipulates the data. Output: Computer presents results. This cycle happens many times as you use software.

1. You type (input). 2. Word processor organizes text (processing). 3. Text appears on screen (output).

Peripheral Devices

Peripherals are devices connected to the main computer. They extend what the computer can do. Some are input-only, some output-only, and some do both (like a touchscreen or multifunction printer).

Choosing the Right Device

Select input and output devices based on the task. For photography, use a camera (input) and monitor (output). For presentations, use keyboard (input), projector and speaker (output).

Quick Check

Is a touchscreen an input device, output device, or both?

Both. It receives touch input and displays output on the screen.
