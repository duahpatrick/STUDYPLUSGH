Introduction to Algebra

Use letters, expressions and equations to describe number patterns and solve unknown values.

Key idea

Algebra lets us work with unknown values using letters, patterns, and rules instead of only known numbers.

Variables and Constants

A variable is a letter or symbol representing an unknown or changing value. A constant has a fixed value.

In 3x + 5, x is the variable, 3 is the coefficient and 5 is the constant.

Expressions and Like Terms

An algebraic expression contains numbers, variables and operations, but no equals sign.

3x + 2x = 5x

Terms are like terms when they have the same variable and power. Unlike terms, such as 3x and 2y, cannot be combined.

Substitution

Substitution means replacing a variable with a known value. Use brackets when substituting a negative number.

If x = 4, then 2x + 3 = 2(4) + 3 = 11.

Solving Simple Equations

An equation has an equals sign. Keep it balanced by doing the same operation to both sides.

x + 7 = 12 → x = 5

3x = 18 → x = 6

Check your answer by putting it back into the original equation.

Patterns and Formulae

A formula is a rule written with symbols. In P = 2l + 2w, substitute the known length and width, then calculate.

Number patterns can also be described using a term-to-term rule.

Worked Example

Solve 2x + 5 = 13.

Subtract 5: 2x = 8. Divide by 2: x = 4. Check: 2(4) + 5 = 13.

Quick Check

If y = 6, find 3y - 2.
