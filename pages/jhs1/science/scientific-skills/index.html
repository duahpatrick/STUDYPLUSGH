JHS 1 Science

Scientific Skills

Learn how scientists ask questions and use evidence.

Key idea

Scientists observe carefully, measure accurately, and use evidence to answer questions.

Observation and Inference

Observation is information gathered with the senses or instruments. An inference is a reasonable explanation based on observations. Scientists record facts before making conclusions.


Example

Observation: a plant near a window has green leaves. Inference: light may help the plant make food.



Measurement and Fair Tests

Use standard units such as metre, kilogram, second and degree Celsius. A fair test changes one variable, measures the result and keeps other conditions constant.


The independent variable is changed; the dependent variable is measured; controlled variables stay the same.



Scientific Method and Safety

A useful investigation follows: question, prediction, plan, observation, results, conclusion and communication. In the laboratory, wear protection, follow instructions, never taste substances and report accidents.


Worked example

To test whether sunlight affects growth, use equal plants, change only light exposure, measure height each day and compare results.



Remember

Good science is careful, honest, repeatable and based on evidence.
