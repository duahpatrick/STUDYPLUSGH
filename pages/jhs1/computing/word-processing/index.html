Word Processing

Create neat documents for school and everyday communication.

Creating a Document

Word-processing software lets you type, edit, format, save and print text. Start by planning the purpose and audience of the document.


Use headings to organise ideas and paragraphs to group related sentences.



Editing and Formatting

Editing changes content; formatting changes appearance. Bold, italic, alignment, font size, spacing and bullets improve clarity when used consistently.



Document Care

Save with a useful filename, proofread before printing and keep a backup. Respect copyright and acknowledge sources.


Remember

Plan, type, edit, format, proofread and save.

What is proofreading?

Checking a document for errors before sharing it.
