Files and Storage Practice

JHS 1 Computing

10 Practice Questions

1. What is a file? Answer: A named collection of data.

2. What is a folder? Answer: A container for related files.

3. Why use clear filenames? Answer: They make work easy to find.

4. Name one storage device. Answer: Flash drive or hard drive.

5. What is cloud storage? Answer: Remote online storage.

6. Why save regularly? Answer: To avoid losing work.

7. What is a backup? Answer: An extra copy of data.

8. Should unknown files be opened? Answer: No.

9. What should you do before removing a flash drive? Answer: Eject it safely.

10. Name one file type. Answer: Document, image or video.
