Files and Storage

Keep digital work organised, available and protected.

Files and Folders

A file is a named collection of data, such as a document or picture. A folder stores related files and other folders. Clear names make work easy to find.


Use names such as Science_Project rather than confusing names such as New Document 4.



Storage Devices

Hard drives, solid-state drives, memory cards and flash drives store data. Cloud storage keeps a copy on remote computers accessed through the internet.



Good File Practice

Save regularly, make backups, scan removable devices and eject drives safely. Do not open unknown files.


Remember

Organise, save, back up and protect your files.

Quick Check

Where should related files be kept?

In a clearly named folder.
