Algorithms

Break problems into clear steps that a person or computer can follow.

What Is an Algorithm?

An algorithm is a finite, ordered set of instructions for solving a problem or completing a task. Each step should be clear and produce a useful result.


Example: Make Milo

1. Boil water safely. 2. Put Milo in a cup. 3. Add hot water. 4. Stir. 5. Add milk if desired.



Good Algorithms

A good algorithm has a clear start and finish, steps in the correct order, and instructions that are not ambiguous. Test it with a simple example and correct errors.



Remember

Understand the problem, plan ordered steps, test the result and improve the instructions.

Quick Check

Why must algorithm steps be in order?

The correct order helps produce the intended result.
