Input and Output

Follow the journey from data to useful information.

Input, Processing and Output

Input is data entered into a computer. Processing is the work done on data. Output is the result presented to the user.


Example

Typing 5 and 7 is input; adding them is processing; displaying 12 is output.



Common Devices

Keyboard, mouse, scanner and microphone are input devices. Monitor, printer, speakers and projector are output devices. A touchscreen can perform both roles.



Remember

Good input supports accurate processing and useful output. Check data before submitting it.

Quick Check

Which device produces a paper copy?

A printer.
