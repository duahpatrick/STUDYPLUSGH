Input and Output Practice

JHS 1 Computing

10 Practice Questions

1. What is input? Answer: Data entered into a computer.

2. What is processing? Answer: Work done on data.

3. What is output? Answer: The result presented to a user.

4. Is a mouse an input device? Answer: Yes.

5. Is a monitor an output device? Answer: Yes.

6. Name one device that can input sound. Answer: Microphone.

7. What does a scanner enter? Answer: Images or printed data.

8. Which device makes paper output? Answer: Printer.

9. Give an example of processing. Answer: Adding two numbers.

10. Can a touchscreen input and output? Answer: Yes.
