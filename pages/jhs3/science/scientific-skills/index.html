Scientific Skills

Observe carefully, investigate wisely and use evidence to explain what happens.

1. Observation

Observation means using the senses to collect information. You may observe colour, shape, smell, texture, sound or movement.

Example: “The leaf is green and smooth.”



2. Inference

An inference is a conclusion based on observations and prior knowledge.

Example: If a plant is wilted and the soil is dry, we infer it needs water.



3. Measurement

Scientists measure length, mass, volume, time and temperature carefully using correct units.

  • Length: centimetres (cm), metres (m)
  • Mass: grams (g), kilograms (kg)
  • Volume: millilitres (ml), litres (l)


4. Experimentation

An experiment tests a hypothesis. Good scientific work uses fair testing by keeping some conditions the same and changing only one variable at a time.



Worked Example

An experiment shows a plant with less sunlight grows shorter than one with more sunlight. What is the inference?

The inference is that sunlight helps plants grow well.



Quick Check

Which is an observation: “The plant needs water” or “The plant is yellow and drooping”?

Practice Questions

  1. State one observation you can make about a ripe banana.
  2. What is the difference between observation and inference?
  3. Name one instrument used to measure temperature.
  4. Why is it important to keep variables constant in an experiment?
