Algebra Revision

Use letters, simplify expressions and solve equations confidently.

1. Variables and Coefficients

A variable is a letter that stands for an unknown number. In the expression 5x + 3, x is the variable, 5 is the coefficient, and 3 is a constant.

When a coefficient is written next to a variable, it means multiplication. So 7y means 7 × y.



2. Simplifying Expressions

Like terms have the same variable and the same power. We can combine them.

  • 3x + 2x = 5x
  • 4a - a = 3a
  • 2x + 3y cannot be combined because they are unlike terms.

To simplify, add or subtract the coefficients only.



3. Substitution

Substitution means replacing a variable with a value.

If x = 4, find 3x + 2.

3x + 2 = 3(4) + 2 = 12 + 2 = 14.

Always replace the variable before doing the calculation.



4. Solving Linear Equations

An equation shows that two expressions are equal. To solve an equation, keep both sides balanced.

Example: x + 7 = 15

Subtract 7 from both sides: x = 8.

Example: 3x = 18

Divide both sides by 3: x = 6.



Worked Example

Solve 2x + 5 = 17.

2x + 5 = 17
Subtract 5 from both sides: 2x = 12
Divide both sides by 2: x = 6
Check: 2(6) + 5 = 17.
